# Panduan trainer

1. Masuk sebagai `trainer@bim.test`.
2. Menu **Review** menampilkan antrean submission.
3. Buka model di Studio, pilih elemen, buat issue di tab Issues (severity info/minor/major/critical).
4. Minta revisi atau approve dengan skor trainer.
5. Approve dengan skor ≥ 75 pada program akan menerbitkan sertifikat (jika belum ada).
6. Dasbor menampilkan rata-rata skor, issue terbuka, dan jumlah revisi.

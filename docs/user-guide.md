# Panduan peserta

1. Masuk dengan akun peserta.
2. Buka **Belajar**, pilih program, baca materi, kerjakan kuis.
3. Di materi wall, klik **Praktikkan Sekarang** untuk membuka BIM Lab di Studio.
4. Di Studio: tool Wall (W), klik dua titik, snap ke grid. Ubah thickness/height di panel kanan.
5. Shortcut: V select, C column, B beam, S slab, D door, N window, M measure, Ctrl+Z undo, Ctrl+S simpan.
6. **Validate** lalu **Submit** untuk penilaian.
7. Jika trainer meminta revisi, perbaiki issue dan submit ulang.
8. Lihat skor di **Kompetensi** dan sertifikat di **Profil**.
